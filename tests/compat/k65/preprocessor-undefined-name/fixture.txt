`#if UNDEFINED` is an error in the original, and the golden is the refusal:

    Line 12: Undeclared eval variable 'NOT_DECLARED_ANYWHERE'

`PPIfNumber -> AllIdent` evaluates the name through the evaluator
(`compiler.inc:24`), and `getevalvar` has no "an unknown name is zero" branch —
so an undeclared condition does not quietly take the false side, which is what
a C programmer would expect it to do. Decision 9 rules the same for K816, and
this is the measurement behind it.

Since G5 K816 says the same thing, in one diagnostic instead of the two
`K816-E0201` deferrals that stood here before: `K816-E0101`, the code an
evaluator bracket already used for a name nothing gives a value. The two
compilers agree that the region is never compiled either way — the difference
would only be whether the build stops, and both stop.

Unlike `eval-refusals` beside it, this refusal is clean in the original: exit
1, with the compiler's own diagnostic, because the preprocessor's evaluation
happens outside the path that aborts.
