Adjacent immediate loads to the same register on separate source lines fold to
the last one.

The legacy compiler produced `A9 05 A2 05 A0 05 60` behind a `sep #$30`
prologue.  K816 produces the same six bytes and no prologue: `@a8 @i8` on
`main` is an assertion about the entry ABI, not a request to set it
(`src/abi.rs`, `K816-E0143`), so the two mode bytes the legacy compiler emitted
at every function entry are absent.  Every imported fixture that compiles
differs from its legacy bytes by exactly that prologue or by an optimizer
decision named in its own note; none differ for any other reason.
