The zero flag a branch shorthand reads must survive the store that follows the
load that set it.

Two differences from the legacy bytes, and both are worth keeping in view:

  - K816 emits `A9 00 64 10` where the legacy compiler emitted `A9 00 85 10`.
    Both are correct - the branch reads the Z the `lda #0` set, and neither
    store writes flags.
  - The `{ a = 2 }` body is empty in K816's output, because `a = 2` is dead:
    the next statement loads A again.  What was left was `D0 00` - a branch
    whose target is the next instruction - and **G8's pass 9 removed it**,
    which is why these bytes are two shorter than the ones this fixture was
    imported with.  It is the pass's witness in the imported corpus: put the
    pass back and `D0 00` returns.

K816 also does *not* rewrite the second zero-store run to STZ where the legacy
compiler did (`85 12 85 11` against `64 12 64 11`).  That is a missed
rewrite, not a wrong one, and it is recorded rather than fixed here: the
optimizer is sub-plan F's and G8 is the only task that touches it.
